🤖 ربات تجمیع‌کننده محتوای تلگرام

رباتی که کانال‌های عمومی تلگرام را می‌خواند، محتوای جدید را فیلتر می‌کند و به مقصد شما ارسال می‌کند. کاملاً رایگان، بدون سرور، مبتنی بر Cloudflare Workers.

Cloudflare Workers D1 Database Workers KV Gemini AI Telegram Bot API

✨ امکانات

🤖 سیستم اسکن و جمع‌آوری محتوا

  • خواندن کانال‌های عمومی از طریق t.me/s/ با سرعت بالا
  • تکنیک حلقه‌ای — در هر اجرای Cron فقط یک منبع بررسی می‌شود (Round-Robin)
  • تشخیص نوع رسانه (عکس، ویدیو، فایل، صوت، استیکر، نظرسنجی، متن)
  • تشخیص تعداد بازدید پست‌ها
  • سیستم ضدتکراری با SHA-256 ذخیره‌شده در D1 به مدت ۷ روز
  • حفظ فرمت‌بندی متن تلگرام (bold، italic، spoiler، quote، code، لینک)

🎯 سه حالت فیلتر

  • فوروارد — ارسال همه پست‌های جدید بدون فیلتر
  • عمیق — فیلتر با کلیدواژه مثبت/منفی + حالت every (AND)
  • وایرال — ارسال پست‌هایی با بازدید بالاتر از آستانه مشخص‌شده

🛡 سیستم ضد تبلیغات (۴ لایه)

  • لایه ۱: الگوهای صریح (تخفیف N٪، کد تخفیف، فرصت محدود، لینک joinchat)
  • لایه ۲: امتیازگذاری — ۲+ نشانگر تبلیغاتی (فروش، خرید، رایگان، تضمین) = تبلیغ
  • لایه ۳: لینک‌های مشکوک (bit.ly، دامنه‌های .vip/.xyz/.shop)
  • لایه ۴: مولتی‌فوروارد (۲+ نام کانال در یک پست)
  • قابل روشن/خاموش روی هر منبع به‌صورت جداگانه

🤖 هوش مصنوعی (Gemini + Workers AI)

  • تحلیل هوشمند کلیدواژه — ۳۰ پست اخیر کانال بررسی می‌شود
  • پیشنهاد کلیدواژه مثبت + منفی به ادمین
  • تأیید تک‌تک کلیدواژه‌ها با دکمه شیشه‌ای
  • گزارش روزانه هوشمند با خلاصه AI
  • Gemini API به‌عنوان provider اصلی (رایگان، پایدار)
  • Workers AI به‌عنوان fallback خودکار

📊 پنل مدیریت تحت وب

  • داشبورد با نمودار (Chart.js) — ارسال، اسکن، رد، خطا
  • مدیریت منابع — افزودن، ویرایش، حذف، ویرایش گروهی
  • تب هوش مصنوعی — تحلیل دستی + تأیید کلیدواژه‌های pending
  • تب لاگ‌ها — جستجو و فیلتر رویدادها
  • تب فعالیت ادمین‌ها
  • آمار ضد تبلیغات (مسدودشده‌های ۷ روز اخیر)
  • بکاپ و بازیابی

🛡 سیستم ادمین

  • ادمین اصلی از متغیر MAIN_ADMIN_ID
  • ادمین‌های فرعی با دسترسی قابل تنظیم (۱۲ دستور محدود)
  • ثبت فعالیت ادمین‌ها + اطلاع به ادمین اصلی
  • ری‌اکشن خودکار 🫡 روی دستورات

💾 سایر امکانات

  • بکاپ و بازیابی با فایل JSON
  • ارسال به گروه‌های تاپیک‌دار (Forum) — هر منبع به تاپیک مربوطه
  • سه دستور ویزارد مرحله‌ای برای افزودن/ویرایش منبع
  • پیام‌های فرمت‌بندی‌شده با blockquote و bold

⏰ زمان‌بندی خودکار (Cron)

ربات ۳ کار خودکار دارد که در زمان‌های مشخص اجرا می‌شوند:

هر ۲ دقیقه
*/2 * * * *
۱. اسکن منابع
یک منبع به نوبت بررسی می‌شود (حلقه‌ای Round-Robin) — این روش از خطای Exceeded CPU limit کلادفلر جلوگیری می‌کند. با ۲۰ منبع، هر منبع هر ۴۰ دقیقه اسکن می‌شود.
هر روز ۲ بامداد ایران
30 22 * * *
۲. تحلیل کلیدواژه با AI
یک منبع با موضوع انتخاب شده، به‌نوبت تحلیل می‌شود. ربات ۳۰ پست اخیر را با Gemini بررسی می‌کند و کلیدواژه‌های مثبت + منفی پیشنهاد می‌دهد. نتیجه به‌صورت pending به ادمین ارسال می‌شود تا تأیید کند.
هر شب ۳ ایران
30 23 * * *
۳. گزارش روزانه
گزارش پست‌های ارسالی ۲۴ ساعت اخیر + گروه‌بندی بر اساس موضوع + پست‌های وایرال + خلاصه هوشمند با AI به ادمین اصلی ارسال می‌شود.
💡 این زمان‌ها در فایل wrangler.toml در بخش [triggers] قابل تغییر هستند.

مراحل

۱. کلون و پیکربندی

git clone <repo>
cd telegram-aggregator
cp wrangler.toml.example wrangler.toml

فایل wrangler.toml را باز کنید و MAIN_ADMIN_ID را تنظیم کنید.

۲. ایجاد منابع Cloudflare

wrangler d1 create aggregator
wrangler kv namespace create AGGREGATOR

شناسه‌های دریافت‌شده را در wrangler.toml قرار دهید.

۳. ایجاد جداول دیتابیس

wrangler d1 execute aggregator --file=./schema.sql

۴. تنظیم متغیرهای حساس

wrangler secret put BOT_TOKEN
wrangler secret put PANEL_PASSWORD
wrangler secret put GEMINI_API_KEY

۵. دیپلوی

wrangler deploy

۶. ثبت دستورات در تلگرام

آدرس زیر را در مرورگر باز کنید:

https://your-worker.workers.dev/setup-commands

۷. فعال‌سازی Webhook

آدرس زیر را در مرورگر باز کنید:

https://your-worker.workers.dev/set-webhook

🌐 پنل مدیریت

پس از دیپلوی، به آدرس زیر بروید:

https://your-worker.workers.dev/panel

با رمز عبوری که در PANEL_PASSWORD تنظیم کرده‌اید وارد شوید.

🛠 تکنولوژی‌ها

  • Cloudflare Workers — محیط اجرای Edge (بدون سرور)
  • D1 — دیتابیس SQLite کلادفلر (منابع، لاگ‌ها، ادمین‌ها)
  • Workers KV — کش و سشن (هش ضدتکراری، انتخاب AI)
  • Cron Triggers — زمان‌بندی خودکار (هر ۲ دقیقه + ۲ کار روزانه)
  • Gemini API — هوش مصنوعی (تحلیل کلیدواژه + خلاصه گزارش)
  • Workers AI — fallback هوش مصنوعی
  • Telegram Bot API — ربات (webhook + inline keyboard)
  • Chart.js — نمودارهای پنل
