۲. خط لوله اسکن (Scan Pipeline)
۵runCron() — انتخاب یک منبع (Round-Robin)
۶scrapeChannel() — خواندن HTML از t.me/s/{channel}
۷parsePosts() → parsePostBlock() — استخراج متن، رسانه، بازدید
۸convertTelegramHtml() — حفظ فرمت‌بندی (bold, italic, spoiler, quote)
۹hashPost() → isDuplicate() — ضدتکراری SHA-256 در D1 (۷ روز TTL)
۱۰matchDeep() / matchViral() — فیلتر حالت (کلیدواژه / بازدید)

۳. سیستم ضد تبلیغات (۴ لایه امتیازدهی)
۱۱scoreAdPost() — امتیازدهی ۰-۱۰۰ با ۴ لایه
۱۲لایه ۱: کلمات (HEAVY_AD_WORDS + MEDIUM_AD_WORDS) — وزن ۱۵-۴۰
۱۳لایه ۲: لینک‌های مشکوک + اموجی تبلیغاتی + آیدی ربات‌ها
۱۴لایه ۳: سیگنال پیش‌درآمد (KV با TTL ۵ دقیقه) — ضریب ×۱.۵
۱۵لایه ۴: ساختار + امتیاز منفی (ریپلای، متن طولانی، دامنه معتبر)
۱۶verdict ≥ ۷۰ → 🚫 مسدود قطعی + لاگ
۱۷verdict ۴۰-۶۹ → ⚠️ sendToQuarantine() + دکمه‌های ❌✅🤖
۱۸verdict < ۴۰ → ✅ عبور → deliverPost()
↓
۴. سیستم هوش مصنوعی (Gemini + Workers AI)
۱۹runAIWithFallback() — Gemini اول، Workers AI fallback
۲۰callGemini() — fetch به Google AI (gemini-2.0-flash → 2.5-flash → 1.5)
۲۱callWorkersAI() — env.AI.run (llama-3.3-70b → 3-8b)
۲۲analyzeSourceWithAI() — تحلیل ۳۰ پست اخیر + استخراج کلیدواژه
۲۳runDailyReport() — خلاصه هوشمند ۲۴ ساعت با AI
۲۴q_ai callback — تحلیل پست قرنطینه‌شده با AI (درخواستی)
