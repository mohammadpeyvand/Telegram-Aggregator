# 🤖 ربات هوشمند تجمیع‌کننده و بازنشر محتوای تلگرام (نسخه ۴)
### Serverless Telegram Content Aggregator & Curator on Cloudflare Workers

یک سیستم سرورلس کامل، فوق‌سریع و رایگان برای تجمیع هوشمند، فیلترسازی و بازنشر محتوا از کانال‌های عمومی تلگرام به کانال یا گروه مقصد، بدون نیاز به سرور مجازی و اجرا شده بر بستر **Cloudflare Workers**.

---

## 🌟 قابلیت‌های کلیدی

### ۱. جمع‌آوری و فیلتر محتوا
- **اسکن بهینه کانال‌های عمومی** از طریق وب‌اسکرپینگ بدون نیاز به لاگین کاربر (`t.me/s/channel`).
- **سه حالت کاری اختصاصی برای هر منبع:**
  - `forward`: بازنشر ساده محتوا.
  - `deep`: فیلتر عمیق مبتنی بر کلیدواژه‌های اصلی، فرعی و ترکیبی با امکان تعریف حداقل امتیاز انطباق.
  - `viral`: بازنشر بر اساس نرخ تعامل و بازدید به همراه قوانین ری‌اکشن شرطی (`reactions_rules`).
- **پیشگیری قطعی از ارسال محتوای تکراری:** با هش SHA-256 محتوا در پایگاه داده Cloudflare D1.

### ۲. فیلترینگ هوشمند تبلیغات و قرنطینه
- **موتور وزن‌دهی کلمات تبلیغاتی (`ad_weights`):** تشخیص خودکار عبارات تبلیغاتی با قابلیت یادگیری خودکار (`auto_learned`).
- **سیستم قرنطینه (`quarantine_config`):** نگهداری پست‌های مشکوک برای بازبینی دستی یا ارسال با تأخیر.

### ۳. هوش مصنوعی دوگانه (Gemini + Workers AI)
- تحلیل عمیق پست‌ها، استخراج کلیدواژه‌ها، بررسی لحن و احساسات متن با **Google Gemini 2.5 Flash**.
- پشتیبانی از **Cloudflare Workers AI** به عنوان پشتیبان در صورت قطعی یا محدودیت سهمیه.
- تولید گزارش تحلیلی روزانه از عملکرد کانال‌ها و وضعیت محتوا.

### ۴. پنل تحت وب مدرن و کاملاً واکنش‌گرا (Admin Web Panel)
- **پشتیبانی از تم تاریک و روشن (Dark / Light Mode):** دکمه تغییر تم در هدر با ذخیره‌سازی انتخاب کاربر در مرورگر و سازگاری خودکار با تم سیستم.
- **بهینه‌سازی کامل برای موبایل:**
  - نوبار لمسی با اسکرول افقی روان.
  - باز شدن دیالوگ‌ها و ویرایشگرها به صورت Bottom Sheet کشویی مناسب لمس با یک دست.
  - جلوگیری از زوم ناخواسته در مرورگرهای موبایل (iOS Safari).
  - چیدمان تک‌ستونه کارت‌های آماری و تنظیم خودکار جدول‌ها.
- **مدیریت کامل منابع و لاگ‌ها:** فعال/غیرفعال‌سازی، ویرایش، حذف، مشاهده زنده لاگ سیستم.
- **بکاپ و بازیابی نسخه ۴:** دانلود و آپلود تنظیمات، منابع، وزن‌های تبلیغاتی و قرنطینه در قالب یک فایل JSON معتبر.
- **سیستم چند ادمینی:** ادمین اصلی و ادمین‌های فرعی با تعیین سطوح دسترسی مختلف.

## 🚀 روش‌های نصب و راه‌اندازی

### روش اول: دیپلوی از طریق Wrangler CLI (پیشنهادی برای توسعه‌دهندگان)

۱. پروژه را کلون کرده و وارد پوشه شوید:
```bash
git clone https://github.com/your-username/telegram-aggregator-bot.git
cd telegram-aggregator-bot/cloudflare-bot
npm install
```

۲. پایگاه داده D1 و فضای KV را ایجاد کنید:
```bash
wrangler d1 create aggregator
wrangler kv namespace create AGGREGATOR
```

۳. شناسه‌های ایجاد شده (Database ID و KV ID) را داخل `wrangler.toml` قرار دهید.

۴. اسکریپت ساخت جداول دیتابیس را اجرا کنید:
```bash
wrangler d1 execute aggregator --file=./schema.sql
```

۵. متغیرهای محرمانه را مقداردهی کنید:
```bash
wrangler secret put BOT_TOKEN
wrangler secret put PANEL_PASSWORD
wrangler secret put GEMINI_API_KEY
```

۶. ورکر را دیپلوی کنید:
```bash
wrangler deploy
```

---

### روش دوم: دیپلوی کاملاً دستی از طریق داشبورد Cloudflare (بدون نیاز به نصب ابزار)

اگر ترجیح می‌دهید بدون استفاده از ترمینال و کامپیوتر پروژه را روی اکانت خود دیپلوی کنید:
1. در داشبورد Cloudflare به بخش **Workers & Pages** بروید و یک Worker جدید بسازید.
2. در بخش **Settings > Variables and Secrets** متغیرهای محیطی (`BOT_TOKEN`, `DESTINATION_CHANNEL`, `MAIN_ADMIN_ID`, `PANEL_PASSWORD`, `GEMINI_API_KEY`) را تعریف کنید.
3. در بخش **D1 SQL Database** یک دیتابیس با نام `aggregator` ساخته و کوئری‌های فایل `schema.sql` را در تب **Console** اجرا کنید.
4. در بخش **KV** یک Namespace به نام `AGGREGATOR` ایجاد کرده و هر دو را در تنظیمات ورکر به عنوان Binding معرفی نمایید.
5. کد `cloudflare-bot/worker.js` را در ویرایشگر آنلاین کپی و **Save and Deploy** کنید.
*(راهنمای تفصیلی و تصویری در فایل `DEPLOYMENT.md` موجود است).*

## ⚙️ متغیرهای محیطی و Secrets

| نام متغیر | نوع | اجباری | توضیحات |
|-----------|-----|--------|---------|
| `BOT_TOKEN` | Secret | بله | توکن ربات تلگرام دریافتی از BotFather |
| `DESTINATION_CHANNEL` | Variable | بله | شناسه یا یوزرنیم کانال مقصد (مثلاً `@my_channel`) |
| `MAIN_ADMIN_ID` | Variable | بله | آیدی عددی ادمین اصلی در تلگرام |
| `PANEL_PASSWORD` | Secret | بله | رمز عبور برای ورود به پنل مدیریت تحت وب |
| `GEMINI_API_KEY` | Secret | اختیاری | کلید API مدل هوش مصنوعی Google Gemini |
| `DB` | D1 Binding | بله | بایندینگ پایگاه داده D1 |
| `KV` | KV Binding | بله | بایندینگ فضای کلید-مقدار KV |

## 📱 دستورات ربات در تلگرام

| دستور | کارکرد |
|-------|--------|
| `/start` | شروع کار، نمایش کیبورد مدیریت و راهنما |
| `/addsource` | افزودن کانال مبدأ جدید به همراه تنظیم حالت (`forward`, `deep`, `viral`) |
| `/listsources` | مشاهده و مدیریت کانال‌های ثبت شده |
| `/scan` | اجرای دستی اسکن و پردازش پست‌های جدید تمامی کانال‌ها |
| `/scansingle` | بررسی و اسکن فوری یک منبع خاص |
| `/adblock` | تنظیم حساسیت و واژگان سیستم ضد تبلیغات |
| `/aianalyze` | فراخوانی هوش مصنوعی برای استخراج هوشمند برچسب‌ها و کلمات کلیدی |
| `/report` | دریافت فوری گزارش آماری و عملکرد ربات |
| `/stats` | خلاصه آمار ۲۴ ساعت گذشته |
| `/backup` | دریافت فایل پشتیبان پیکربندی‌ها |
| `/restore` | ارسال فایل JSON بکاپ برای بازیابی سریع |
